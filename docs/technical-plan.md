# 千问杯决赛技术方案摘要

## 1. 项目概述

本方案面向千问杯多模态推理挑战赛决赛，围绕数值、计数、空间、物理常识、感知和关联六类能力开展模型后训练。

- 初赛模型：v4，平台成绩 41.8 分
- 决赛模型：rlx30，平台最高成绩 20.2 分
- 决赛口径基线：v4-SFT 18.2 分
- RL 增益：2.0 分

## 2. 总体路线

采用“教师蒸馏 SFT + GRPO 小剂量强化学习”两阶段路线。

### 阶段一：教师蒸馏与 SFT

使用 Qwen3.6-27B 教师模型构建多模态指令数据，得到 113,159 条蒸馏样本，再筛选出 24,251 条 train_v4 数据。基于 Qwen3.5-0.8B 多模态模型进行 LoRA 微调，配置为 2 epoch、seed 42、all-linear。

SFT 阶段优先覆盖六类能力，目标是构建稳定的能力宽度和与平台一致的答案格式。

### 阶段二：GRPO 强化学习

决赛规则要求以初赛模型为起点进行 RL，不能修改模型结构或引入其他预训练权重。最终从 RAVEN 九宫格抽象推理数据中构建 1,709 条 RL 数据池，使用 TRL GRPOTrainer 进行小剂量训练。

最终配置：

| 参数 | 配置 |
| --- | --- |
| 训练步数 | 30 |
| 学习率 | 1e-6 |
| KL 系数 | 0.2 |
| 组大小 K | 8 |
| 最大生成长度 | 256 |
| 随机种子 | 42 |

## 3. 奖励设计

奖励函数与平台评测口径保持一致：

- 正确提取 boxed 答案且答案匹配：1.0
- 能提取 boxed 答案但答案错误：0.05
- 无法提取 boxed 答案：0.0

答案提取使用反向查找 boxed 标记和括号深度计数，归一化规则同步处理空白、标点和全半角符号，减少训练奖励与平台判分之间的偏差。

## 4. 实验结论

### 4.1 小剂量 RL 更稳定

剂量轴实验显示平台成绩并非随训练步数单调增加：20 步为 15.2 分，30 步达到 20.2 分，50 步降至 17.8 分，60 步降至 16.8 分。对 0.8B 模型而言，较大更新容易造成灾难性遗忘。

### 4.2 数据分布匹配比覆盖面更重要

单维高浓度 RAVEN 池取得 20.2 分，六维均衡池为 17.8 分。实验表明，RL 数据池与隐藏评测分布的匹配度比表面上的能力覆盖面更关键。

### 4.3 推理侧消融

在模型权重保持一致的条件下，greedy 解码相较平台默认采样配置下降约 3 分。最终提交保持平台默认推理参数。

## 5. 工程与合规

训练前对初赛起点做权重校验，训练、导出、打包和校验步骤均脚本化。最终提交包采用平铺结构，并对文件完整性进行校验。

本摘要不包含模型权重、比赛私有评测集、训练图片、内部服务器路径或运行凭据。复现时需要自行准备兼容的模型、公开数据集和硬件环境。
